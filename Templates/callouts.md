
 Here's the complete list of built-in callouts with their colors:

  | Callout Type | Aliases            | Color     | Icon     |
  |--------------|--------------------|-----------|----------|
  | [!note]      | -                  | 🔵 Blue   | Pencil   |
  | [!abstract]  | summary, tldr      | 🔷 Cyan   | Document |
  | [!info]      | -                  | 🔵 Blue   | Info     |
  | [!todo]      | -                  | 🔵 Blue   | Checkbox |
  | [!tip]       | hint, important    | 💠 Teal   | Flame    |
  | [!success]   | check, done        | 💚 Green  | Check    |
  | [!question]  | help, faq          | 🟡 Yellow | Question |
  | [!warning]   | caution, attention | 🟠 Orange | Alert    |
  | [!failure]   | fail, missing      | 🔴 Red    | X        |
  | [!danger]    | error              | 🔴 Red    | Zap      |
  | [!bug]       | -                  | 🔴 Red    | Bug      |
  | [!example]   | -                  | 💜 Purple | List     |
  | [!quote]     | cite               | 🩶 Gray   | Quote    |

  Where to See Them

  In Obsidian:
  1. Open Settings → Help → Documentation
  2. Or press Ctrl/Cmd + P → Search "Help" → "Callouts"
  3. Visit: Settings → Appearance → CSS snippets (to customize)

  Online:
  - Official docs: help.obsidian.md/Editing+and+formatting/Callouts
  - Community forum: "All Callout Styles for Reference" thread
