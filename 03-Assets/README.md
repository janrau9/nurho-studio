# Assets Registry

This folder tracks reusable assets. **Don't commit large files directly** - instead, link to their actual locations.

## How to Use

### Adding an Asset
1. Store the actual file in your local assets folder (outside git)
2. Create a note here with:
   - File path / cloud link
   - License info
   - Tags for searchability
   - Preview image if applicable

### Asset Note Template
```markdown
# Asset Name

## Info
| Field | Value |
|-------|-------|
| Type | Music / SFX / Template |
| Location | `D:/Assets/Music/track.mp3` or cloud link |
| License | CC0 / Royalty-free / Purchased |
| Source | Where you got it |

## Tags
#upbeat #electronic #60bpm

## Notes
When to use, what it pairs well with, etc.
```

## Folders

### Music/
Background tracks, organized by mood/genre

### SFX/
Sound effects - whooshes, impacts, transitions

### Templates/
DaVinci Resolve projects, ComfyUI workflows, etc.

## External Asset Locations
- **Music**: `D:/Assets/Music/` (or your path)
- **SFX**: `D:/Assets/SFX/`
- **Stock footage**: Cloud storage link

## Recommended Free Sources
- **Music**: Pixabay, YouTube Audio Library, Uppbeat
- **SFX**: Freesound.org, Pixabay
- **Stock video**: Pexels, Pixabay
